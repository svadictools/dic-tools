05  /  3D tips
Turn your type into a 3D print.
Set your letters in Illustrator, give them depth in Blender, then clean them up so they print right.
Click to view the steps ▼
In Illustrator
1.
Outline the type
Type › Create Outlines
2.
Merge touching letters
Window › Pathfinder › Unite
3.
Turn strokes into shapes
Object › Path › Outline Stroke
4.
Remove extra points
Object › Path › Clean Up, then Simplify
5.
Save it
File › Export As › SVG
In Blender
6.
Bring it in and set the size
File › Import › SVG, then press N and type the size in mm
7.
Make it thick
Right panel › green curve tab › Geometry › Extrude
8.
Make it solid
Object › Convert › Mesh
Clean it up
9.
Remove doubled points
Tab, then A, then Mesh › Merge › By Distance
10.
Remove broken faces
Mesh › Clean Up › Degenerate Dissolve
11.
Fix inside-out faces
Mesh › Normals › Recalculate Outside
12.
Check it with the 3D Print Toolbox
N › 3D-Print tab › Check All
13.
Clean up and make it solid
3D-Print tab › Clean Up › Make Manifold, then Check All again
14.
Save for printing
File › Export › STL
First time? Add the free 3D Print Toolbox once: Edit › Preferences › Get Extensions.
